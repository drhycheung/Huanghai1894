# 黄海 1894

公元 1894 年，甲午战争。黄海之战，北洋水师遭遇重创——致远沉没，五舰尽毁。这是历史上真实发生过的事。

然而在这部小说里，历史在那一刻分了一条岔：北洋以两发侥幸命中的炮弹，让日本舰队误以为北洋弹药充足，从而退去——北洋"侥幸"获胜。没有人意识到，这条岔路将通往一个与正史迥异的国度。

胜利的狂欢掩盖了一个真相：这个国家早已是纸糊的老虎。军费被挪去修颐和园，西学人才被制度隔绝在权力之外，满朝上下无人真正相信这场胜利。假若日本再来一次，北洋拿什么迎敌？

于是，李鸿章、张之洞、刘坤一、袁世凯、光绪皇帝——这一群各怀私心、互不相让的人，为了各自盘算的利益，被推着共同走向了"立宪"。他们没有一个想救这个国家，他们只想救自己的利益。

可当这些利益被绑在一起，这个摇摇欲坠的古老帝国，竟真的走出了另一条路。

故事以留美幼童出身的容闳为主线视角，串联起詹天佑、唐绍仪、陈金揆等留美幼童的命运——他们是这个国家最早睁眼看世界的人，学成归国后却被制度拒于权力门外。

北洋的"大捷"，靠的是最后两发炮弹——打出去之后，这个国家的海军，就真的什么都没有了。

没有人想过救这个国家，可每个人都救了自己的利益——然后这个国家，居然，活了。

## 关于本项目

本项目是一个基于架空历史的小说创作尝试。内容纯属虚构，并非真实历史。灵感来源于阅读北洋水师历史时的个人幻想与脑洞，旨在满足创作欲望。

本项目也是探索 AI 写作协作模式的一次实践。具体流程如下：

1. **人类主导**：由我制定宏观故事线、提供核心主题、设定角色以及提出写作风格要求。
2. **AI 辅助**：根据上述指令，由 AI 生成具体章节内容。
3. **人工审阅**：我对 AI 生成的内容进行审阅、修改和完善。

这不仅是利用 AI 提升效率的手段，更是一种探索"人机协作"模式的尝试。我们希望通过这种合作方式，在发挥 AI 优势的同时，保持人类的创造力与主导权，探索如何与 AI 共存并避免被其取代。
